Task-1 Data Cleaning Project - Airbnb Dataset

## 📌 Project Overview

This project focuses on cleaning and preprocessing the Airbnb NYC 2019 dataset.
The goal is to handle missing values, remove duplicates, and prepare the data for analysis.

## 📂 Dataset

* Dataset Name: AB_NYC_2019.csv
* Source: Airbnb NYC Open Data
* Total Records: 48,895
* Features: 16 columns
## 🛠️ Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
## 🔧 Data Cleaning Steps

1. Handled missing values
2. Filled null values in:

   * name → "Unknown"
   * host_name → "Unknown"
   * reviews_per_month → 0
3. Replaced missing values in last_review
4. Removed duplicate rows
5. Dropped unnecessary columns (id, host_id)
## 📊 Data Visualization

* Price Distribution (Histogram)
* Room Type Distribution (Bar Chart)
* Neighbourhood Analysis
* Price vs Room Type (Boxplot)
* Correlation Heatmap

## 📈 Results

* Cleaned dataset with no missing values
* Improved data quality for analysis
* Visual insights generated using charts
