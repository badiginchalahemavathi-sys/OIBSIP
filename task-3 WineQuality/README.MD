# Wine Quality Prediction Using Machine Learning

## Project Overview

This project aims to predict the quality of wine based on its chemical properties using Machine Learning algorithms. The dataset contains various physicochemical features such as acidity, density, pH, alcohol content, and sulphates. By analyzing these features, the model predicts whether the wine is of good quality or not.

## Objectives

* Analyze wine quality data.
* Perform data preprocessing and feature scaling.
* Train multiple machine learning models.
* Compare model performance and identify the best model.
* Predict wine quality based on chemical characteristics.

## Dataset

The dataset contains the following features:

* Fixed Acidity
* Volatile Acidity
* Citric Acid
* Residual Sugar
* Chlorides
* Free Sulfur Dioxide
* Total Sulfur Dioxide
* Density
* pH
* Sulphates
* Alcohol

Target Variable:

* Quality

The performance of the following models was compared:

* Random Forest Classifier

The model with the highest accuracy was selected as the best-performing model.

## Conclusion

The Wine Quality Prediction system successfully predicts wine quality using machine learning techniques. Among the tested models, the best-performing classifier achieved the highest accuracy and can be used for quality assessment based on chemical properties.
