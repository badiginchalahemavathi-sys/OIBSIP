# Exploratory Data Analysis (EDA) on Menu/Nutrition Dataset

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a menu/nutrition dataset.  
The main objective is to clean the data, analyze patterns, understand nutritional values, visualize important trends, and generate useful business insights.

## Dataset Description

The dataset contains information about food items including:

- Category
- Item Name
- Calories
- Total Fat
- Sodium
- Carbohydrates
- Sugars
- Protein
- Vitamins and other nutritional details

## Objectives

- Load and understand the dataset
- Perform data cleaning
- Calculate descriptive statistics
- Analyze nutritional patterns
- Visualize data using charts
- Identify important insights
- Provide recommendations

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning Steps

- Checked missing values
- Removed duplicate records
- Verified data types
- Prepared data for analysis

## Exploratory Data Analysis

Performed:

### Descriptive Statistics

Calculated:

- Mean
- Median
- Mode
- Standard Deviation


### Category Analysis

Analyzed the number of items available in each category.


### Nutrition Analysis

Studied:

- Calorie distribution
- Protein levels
- Sugar content
- Fat and carbohydrate relationships


### Data Visualization

Created:

- Bar charts
- Histograms
- Box plots
- Correlation heatmaps
- Distribution plots


## Key Insights

- Food items have different nutritional patterns across categories.
- Some items contain very high calories and sugar.
- Protein-rich items can be identified for healthier choices.
- Calories have relationships with fat and carbohydrates.

## Recommendations

- Promote healthier food options.
- Highlight nutritional information for customers.
- Create low-calorie menu sections.
- Improve product planning using data insights.

## Conclusion

EDA helped to understand the dataset, discover trends, and generate meaningful insights that can support better decision-making.
